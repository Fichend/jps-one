# JPS One Email Draft

Use this skill to create human-reviewable outreach and follow-up emails.

Inputs:

- Lead and contact.
- Product match recommendation.
- Country/language.
- Template style and constraints.
- JPS product citations.

Output:

- Subject.
- Body.
- Personalization points.
- Review issues.
- Suggested follow-up.

Safety:

- Default to draft + human review.
- Do not bulk-send by default.
- Respect opt-out, rejection, and invalid contacts.
