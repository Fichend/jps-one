# JPS One Website Analysis

Use this skill after candidate companies are discovered.

Target pages:

- Home
- About
- Products
- Contact
- Brands
- Catalog files

Output:

- Company summary.
- Product line.
- Customer type.
- Emails, phones, WhatsApp, and public social links.
- Evidence URLs and snippets.
- Confidence and warnings.

Boundaries:

- Read only public content.
- Preserve citations for every non-obvious claim.
- Do not invent contacts.
