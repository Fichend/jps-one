# JPS One Product Match

Use this skill to decide whether a lead is worth developing and which JPS products to recommend.

Inputs:

- Lead profile.
- Website evidence.
- Product category target.
- JPS product RAG results.

Output:

- Match score.
- Recommended products.
- Match reasons.
- Evidence IDs or citations.
- Risks and missing information.
- Outreach angle.

Rules:

- Prefer evidence-backed reasons.
- Mark uncertainty clearly.
- Do not recommend price-sensitive details unless authorized.
