# JPS One Skill Runtime

This directory stores project-local skill playbooks. They document repeatable operating procedures for JPS One, and can later be promoted into Codex user skills.

Skill rules:

- A skill describes workflow, inputs, tools, checks, and safety boundaries.
- A skill does not store secrets.
- A skill should point to code modules and docs, not duplicate large code.
- A skill should end with verification and handoff expectations.

Initial skills:

- `jps_one_cloud_ops`
- `jps_one_lead_hunt`
- `jps_one_website_analysis`
- `jps_one_product_match`
- `jps_one_email_draft`
- `jps_one_quote_draft`
- `jps_one_integration_diagnostics`
