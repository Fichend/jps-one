# Search Connectors

Search connectors provide customer discovery inputs. The canonical customer discovery sources are search engines, maps, websites, industry directories, B2B platforms, and user uploads.

Meta/Facebook is not treated as a general customer search engine.

First version:

- Preserve existing Tavily and Jina behavior.
- Expose capability diagnostics.
- Normalize search results into `title`, `url`, `snippet`, `source`, and `confidence`.
