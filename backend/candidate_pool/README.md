# Candidate Pool

候选池是 JPS-One 搜索任务的统一客户承载层。搜索器、地图、社媒和资料补全产生的结果都先进入候选池，经过实体合并、目标类型校验、地区校验、评分排序后，再切出推荐 Top N。

## Pipeline

1. `merge.py` 将多源搜索结果合并成候选客户实体。
2. `profile_merge.py` 把资料补全得到的介绍、联系方式、社媒和证据回写到候选客户。
3. `goal_guard` 识别目标类型和地区匹配，防止学校任务混入制造商、泰国任务混入加拿大客户。
4. `ranking.py` 按目标匹配、地区、产品场景、JPS 评分、联系方式和证据排序。
5. `intelligence.py` 使用配置的大模型生成 AI 复核：企业介绍、匹配判断、风险、缺失信息和下一步动作。

## Rules

- 候选池不静默丢弃客户；推荐客户只是排序后的 Top N。
- Instagram、Facebook、LinkedIn、邮箱、电话是补全和加分项，不作为默认删除门槛。
- 后端规则是最终裁判；LLM 只负责补充解释和业务可读性，不覆盖确定性排除。
