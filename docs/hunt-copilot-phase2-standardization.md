# Hunt Copilot 阶段二修复说明

本阶段聚焦搜索稳定性和历史复用，不改变搜索 API 配置入口。

## 已完成

- 新增 `strategy_fingerprint`：把地区、客户类型、产品关键词、排除对象、硬条件、候选/最终数量规范化后生成稳定策略指纹。
- 新增 `SearchPlanCompiler`：同一策略会生成同一组内部工具查询，减少“同背景每次搜索不一样”的波动。
- Tool Plan 增加 `plan_hash` 和内部摘要，用于后端追踪，不在前端展开复杂搜索计划。
- Copilot session 增加 `similar_history`：自动找相似历史会话，前端历史栏可一键复制复用。
- LeadExtract 最终结果改为对“已有线索 + 新线索”统一按 JPS 评分排序后截取 Top N，避免早期低质量客户占满名额。

## 受控边界

- Tavily、Apify、Google Maps、Playwright/Chrome 的配置入口不变。
- 搜索计划仍由后端状态机确认后执行，不允许 LLM 直接调用付费工具。
- 历史会话只做策略复用，不自动复用过期联系方式。

## 验收点

- 相同策略即使输入顺序不同，也得到相同 `plan_hash` 和查询顺序。
- 新结果质量更高时，可以替换早期低分结果进入最终 Top N。
- 新建任务页左侧历史栏会显示相似历史策略。
