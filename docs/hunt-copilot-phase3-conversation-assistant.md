# Hunt Copilot 阶段三修复说明

本阶段聚焦“对话更像业务助手”，不改变搜索通道和付费 API 配置。

## 已完成

- 新增 `conversation_guide.py`：根据当前策略缺失项、冲突和状态生成下一步建议回复。
- Copilot session 新增 `suggested_replies`，前端对话输入框上方显示可点击回复 chips。
- 缺失字段提示改成业务员能理解的中文名，例如“JPS 产品关键词”“必需字段”，不再直接暴露后端字段名。
- Response Builder 优化了缺失硬条件、预检完成、策略接近完成时的回复话术。
- 前端聊天区保留原有布局，只增加最小的建议回复按钮，不改动主要 UI。

## 当前边界

- 建议回复只用于补齐策略和确认策略。
- 通道检查、正式执行仍建议使用右侧受控按钮，避免聊天误触付费执行。
- LLM 仍只负责理解和 patch；后端状态机继续负责安全校验。

## 验收点

- 用户只描述目标时，系统会给出硬条件/关键词等下一步建议。
- 用户不用记字段名，可以点击建议回复继续完成策略卡。
- 聊天回复更偏业务说明，而不是机械输出后端字段。
