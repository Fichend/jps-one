# Skill Design

Skills are repeatable work instructions.

Project-local skills live in:

```text
backend/skills_runtime/
```

Initial skills:

- `jps_one_cloud_ops`
- `jps_one_lead_hunt`
- `jps_one_website_analysis`
- `jps_one_product_match`
- `jps_one_email_draft`
- `jps_one_quote_draft`
- `jps_one_integration_diagnostics`

Each skill should define:

- when to use it;
- required inputs;
- workflow steps;
- tools and modules;
- verification;
- safety boundaries.
