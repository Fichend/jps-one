# 前端视觉升级功能回归清单

本清单用于约束医疗青绿视觉升级：只调整展示层、业务文案和页面布局，不删除路由、接口、状态或业务操作。

## 全局导航与权限

- 任务看板 `/`
- 一键搜索 `/hunts/new`
- 深度搜索 `/deep-search`
- 邮件发送 `/integration-center`
- 客户池 `/leads`
- 产品库 `/products`
- 匹配中心 `/matches`
- 报价中心 `/quotes`
- 知识库 `/knowledge`
- 管理员配置中心 `/foundation`
- 管理员系统设置 `/settings`
- 当前用户查询与管理员入口控制保持不变

## 任务看板

- 历史任务继续按日期分组，并为每个任务保留独立卡片
- 一键搜索与深度搜索使用独立类型标识
- 任务详情、自动队列详情入口保持不变
- 导入客户池、删除任务及二次确认保持不变
- 运行中、排队、完成、失败状态保持不变
- 任务队列、邮件状态、失败记录、发送记录和回复记录保留在“系统运行信息”折叠区

## 一键搜索

- 历史会话、加载会话、复制会话保持不变
- 对话输入、推荐回复和搜索方案实时更新保持不变
- 必填资料、数量、预算、执行规则设置保持不变
- 方案确认、渠道检查、预检和正式执行保持不变
- 对话区和右侧方案区继续独立滚动，不带动整个页面

## 深度搜索

- 公司官网、公司名、国家地区和产品方向输入保持不变
- 独立创建深度搜索任务及结果轮询保持不变
- 公司档案、邮箱、电话、社交链接和业务证据保持不变
- 完成、运行中、失败和空结果状态保持不变
- 仅移除面向业务员无意义的内部工具调用次数展示

## 任务详情与自动化任务

- 任务续跑、候选客户、推荐客户、线索、阶段进度和成本信息保持不变
- 候选客户选择、书签、人工校准、深度补全和背调导出保持不变
- 邮件资料提取、审批、发送和回复检测保持不变
- 自动化任务取消、重试、阶段切换和发送序列详情保持不变
- SSE 实时更新和 React Query 刷新策略保持不变

## 客户池

- 来源任务导入、客户分组、搜索和详情抽屉保持不变
- 官网、联系方式、评分、公开证据和来源信息保持不变
- 所有弹窗和抽屉继续使用独立滚动区域

## 邮件发送

- 邮件任务选择、显示名称、备注和隐藏任务保持不变
- 客户资料编辑、书签、发送名单切换和公开邮箱补全保持不变
- 模板识别、模板库新增/编辑/删除/应用保持不变
- 一键代发预览、逐客户编辑、确认入队和幂等保护保持不变
- 发送进度、失败明细和历史记录保持不变

## 管理员功能

- 集成配置、系统设置、模型、搜索、邮件和通知配置保持不变
- 配置保存、连接测试和权限控制保持不变
- 技术配置只在管理员区域展示，业务页面使用业务化文案

## 发布前验证

- `tsc -b`
- `vite build`
- 对比 `frontend/src/api/client.ts`：本次不修改 API 接口定义
- 对比 `frontend/src/routes/routeTree.ts`：本次不删除或新增路由
- 对比所有 `useMutation` 与关键 `onClick`：本次不删除业务动作
