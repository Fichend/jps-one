# JPS One Documentation

This folder is the source of truth for JPS One architecture, operations, and future implementation.

Read in this order:

1. `CURRENT_STATE.md` - current local/cloud state and known boundaries.
2. `STANDARDS/README.md` - product installation, usage, release, and permission standards.
3. `ARCHITECTURE.md` - target system structure.
4. `DATA_MODEL.md` - core entities and relationships.
5. `RAG_DESIGN.md` - knowledge ingestion and retrieval design.
6. `MCP_DESIGN.md` - MCP tool contract design.
7. `SKILL_DESIGN.md` - project skill playbook design.
8. `INTEGRATIONS.md` - Meta, WhatsApp, search, email, and model boundaries.
9. `DEPLOYMENT.md` - release and rollback plan.
10. `OPERATIONS.md` - daily checks and troubleshooting.

The long-form design source is `JPS_ONE_SYSTEM_RESTRUCTURE_DESIGN.md`.
